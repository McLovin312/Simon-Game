Press Any Key to Start

How to Play:

Press any keyboard key to start the game. The game will flash a single color and play a sound. Click the matching color. If correct, the game will repeat the first color and add a new color to the sequence. You must repeat the entire sequence from the very beginning every time a new color is added. If you click the wrong color or click out of order, the background will flash red and the game will end. Press any key to restart from Level 1.
